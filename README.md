# FreelanceHub

React (Vite) frontend and Django REST API. Local development uses two servers.

For PowerShell setup, environment variables, JWT examples, and backend validation, see the [Django and REST Framework setup guide](backend/README.md).

## Layout

- `frontend-app/`: React source, Vite configuration, npm dependencies.
- `backend/`: Django apps, models, migrations, REST API, and Django admin.
- `documents/`: proposed workflow and design specifications.

The former Django page routes are no longer mounted. Their Python modules are retained for reference during migration; React currently provides a read-only marketplace starter. Registration, dashboards, messaging, and other legacy screens still need React implementations. Existing API authorization issues must be addressed before deployment.

## Backend (CMD, from repository root)

```cmd
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r backend\requirements.txt
cd backend
python manage.py migrate
python manage.py runserver
```

Optional demo data: `python manage.py seed_data`. Django admin: http://127.0.0.1:8000/django-admin/.

## Frontend (second CMD, from repository root)

```cmd
cd frontend-app
npm install
npm run dev
```

Open http://localhost:5173. Vite forwards `/api/` and `/media/` to Django on port 8000. [Vite proxy documentation](https://vite.dev/config/server-options#server-proxy). No separate CORS setup is needed for these same-origin browser requests. The development proxy is not a production server; configure equivalent routing when deploying.

## Checks

```cmd
cd backend
python manage.py check
python manage.py test api
```

```cmd
cd frontend-app
npm run lint
npm run build
```

API health: `/api/health/`; services: `/api/services/`; categories: `/api/categories/`; JWT tokens: `/api/auth/token/`.

## Repository housekeeping

Keep the SQLite database at `backend/db.sqlite3`; run management commands from `backend/` to use the intended project configuration. The database, uploaded media, virtual environments, npm dependencies, caches, and build output are ignored by Git.

`frontend-app/dist/` is generated by `npm run build`. Python bytecode caches and Vite caches are generated automatically and can be removed when the development servers are stopped.

The Git working tree contains the earlier relocation of the original root-level Django files into `backend/`. Review those deletions together with the new backend and frontend directories when committing.
